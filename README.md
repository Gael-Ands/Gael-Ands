## Enfoque Actual

### RINGCARD — By BlackDucks
Desarrollo de un sistema de escritorio robusto enfocado en la gestión financiera personal y el control estricto de movimientos bancarios junto al manejo de tarjetas de crédito.

* **El Objetivo Principal:** Salvaguardar la salud financiera del usuario mediante un sistema automatizado de notificaciones por correo electrónico, recordando fechas de corte y límites de pago para evitar recargos.
* **Tech Stack Activo:** Java Swing | NetBeans | PostgreSQL
* **Metodologías y Prácticas:** Implementación de arquitectura de software limpia, metodologías de ingeniería y optimización avanzada de bases de datos relacionales.
